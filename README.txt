【プレビュー方法】
1. VS Codeで上記フォルダを開く
2. index.htmlを右クリック
3. 「Open with Live Server」があれば選択
   または、index.htmlをエクスプローラーからブラウザで開く

【重要】
このデモでは、写真は仮のオンライン画像を使用しています。
お店の公式写真ではありません。実際の公開前に、許可を得た公式写真へ差し替えてください。
公式ロゴは、提供された写真をそのままロゴファイルとして切り抜き加工していません。
サイト内のロゴは、左側に眼鏡をモチーフにした仮のSVGマーク、右側に「CAFE」「めがね書房」を配置しています。
正式ロゴの正確な再現には、可能であれば背景透過のロゴ画像データをご用意ください。

【画像の差し替え】
現在の画像はCSS内で指定しています。公式画像を images フォルダに保存したら、
style.css 内の該当する background-image: url(...) を
例: background-image: url("images/shaved-ice.jpg");
のように変更してください。

【公開前に要確認】
- 実際の公式メニュー写真への差し替えと画像の利用許可
- メニュー名・値段・提供時期
- 営業時間・定休日・駐車場情報
- メールボタンと予約ページの実機テスト
- 正式ロゴへの差し替え

このサイトはクライアント確認用のデモです。掲載情報は公開前にお店へ確認してください。
